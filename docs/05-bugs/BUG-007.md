| Evidência | `docs/04-sessoes-exploratorias.md` (notas de 16:12) e teste `EXP-API a resposta não deveria expor X-Powered-By` |

## Descrição
As respostas da API incluem o cabeçalho `X-Powered-By: Express`, que revela a tecnologia do servidor. É uma recomendação de segurança comum desativá-lo, porque facilita a escolha de ataques direcionados.

## Passos para reproduzir
1. Iniciar a aplicação com `npm start`.
2. Executar `curl -i -X HEAD http://localhost:3000/api/payslips/latest`.
3. Observar o cabeçalho `X-Powered-By: Express`.

## Resultado obtido
Cabeçalho `X-Powered-By: Express` presente.

## Resultado esperado
Resposta sem esse cabeçalho.

## Impacto
Baixo. Não é uma vulnerabilidade por si só; apenas reduz informação útil para quem investiga o sistema.

## Sugestão de correção
Desativar com `app.disable('x-powered-by')` em `src/app.js` (ou usar o pacote `helmet`).

## Teste que cobre o defeito
`tests/api/api.test.js`: "EXP-API a resposta não deveria expor X-Powered-By" (marcado como `todo: 'BUG-007'` até a correção).
